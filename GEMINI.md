# Codebase Documentation for ngmorrow1029.github.io

This document provides an overview of the codebase for this personal portfolio website, generated by Gemini Code Assist.
## 1. Project Overview

This is a personal portfolio website built using the [Astro](https://astro.build/) framework. It is designed to be a minimal, fast, and content-focused static site.

## 2. Technologies & Architecture

*   **Framework**: [Astro](https://astro.build/) is used as the core static site generator. Astro components (`.astro` files) are found in `src/pages/`.
*   **Runtime**: Node.js (v20) is the runtime environment. Project scripts and dependencies are managed with **npm**, as defined in `package.json`.
*   **Styling**: SCSS (Sass) is used for styling, following a strict **7-1 pattern**. Each subdirectory in `src/styles/` contains an `_index.scss` file that forwards its modules, and `main.scss` uses `@use` to import them.
    *   A modern CSS reset is used for consistent base styling across browsers.
*   **JavaScript**: Vanilla JavaScript is used for client-side interactivity.
*   **Deployment**: Continuous deployment is handled by GitHub Actions, which builds and deploys the site to GitHub Pages on every push to the `Master` branch. The workflow is defined in `.github/workflows/deploy.yml`.

## 4. Key Features & Code

### 4.1. Contact Form Submission

The file `public/assets/js/form-submission-handler.js` manages the contact form.

*   **AJAX Submission**: It prevents the default form submission and sends the data asynchronously using `XMLHttpRequest`.
*   **Validation**: Includes a function `validEmail()` to check for a correctly formatted email address on the client side.
*   **Spam Prevention**: A "honeypot" field is implemented. If this hidden field is filled out (likely by a bot), the submission is blocked.
*   **User Feedback**: Hides the form and shows a "thank you" message upon successful submission.

### 4.2. Responsive Navigation

The navigation is fully responsive, handled by CSS in `src/styles/components/_navigation.scss`.

*   On larger screens, it's a standard horizontal navigation bar.
*   On smaller screens (<= 961px), it collapses into a "hamburger" menu.
*   The hamburger icon (`.nav-toggle`) is a pure CSS implementation that animates into an "X" when the menu is open.
*   JavaScript is used to toggle the `aria-expanded` attribute and a `.nav-open` class to control the visibility of the mobile menu.

### 4.3. Deployment Pipeline

The `.github/workflows/deploy.yml` file automates deployment.

*   **Trigger**: The workflow runs on a `push` to the `Master` branch or can be triggered manually (`workflow_dispatch`).
*   **Jobs**:
    1.  `build`: Checks out the repository, installs dependencies using `npm` (via `withastro/action`), and builds the Astro site.
    2.  `deploy`: Depends on the `build` job. It uses the `actions/deploy-pages@v4` action to deploy the built artifacts to GitHub Pages.
